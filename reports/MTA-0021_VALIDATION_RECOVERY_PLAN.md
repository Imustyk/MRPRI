### Как outcome-based отбор влияет на ROC-AUC

При идеальном case-control отборе только по истинному бинарному классу, случайном внутри каждого класса, ROC-AUC не зависит от prevalence. Здесь отбор делается по **предполагаемому исходу noisy-экстрактора**, году, читаемости и подтипам admitted/partially_admitted: он может менять распределение сложности и скорингов внутри классов, поэтому наивная AUC не обязана сохраняться. Изменение смеси admitted/partial также меняет positive-case mix. Для целевой популяции нужны вероятности включения, корректировка состава/весов и учёт кластеров либо честное ограничение estimand обогащённым проверенным пулом. Непрошедшие OCR документы имеют неизвестную вероятность распознавания; обычное взвешивание уже распознанных не устраняет этот bias. PR-AUC, precision, prevalence и lift не переносятся на естественную частоту нарушений из искусственно обогащённой выборки без дополнительных оснований. Ни одна AUC в этом шаге не рассчитывалась.

### Реальные пределы численности

Сейчас новые verified классы: **0+/0−**. Даже в лучшем варианте один negative меняет specificity на1/6≈16.7 процентного пункта. Для прежней цели точности95% CI с полушириной около±0.10 консервативное биномиальное планирование z²/(4h²)≈96.04 даёт97 независимых positives и97 negatives. Это ориентир для sensitivity/specificity, не готовый power-analysis парной разницы ROC-AUC; кластеризация увеличит нужный объём. Для GO superiority-эксперимента отдельно заранее задать минимально значимый парный эффект и мощность, при необходимости смоделировать дизайн без просмотра финальных тестовых результатов.

**Сейчас NO-GO для формального MTA-0020 сохраняется.** Только после верификации возможен LIMITED GO для описательного пилота/анализа ошибок; сильный вывод о превосходстве модели не разрешён. Локальный подтверждённый пул недостаточен; нечитаемый backlog может дать дополнительные решения, но их годы и классы пока неизвестны. Нельзя утверждать, что вся локальная коллекция уже исчерпана. Массовое расширение/скачивание или OCR всего backlog не запускались.
