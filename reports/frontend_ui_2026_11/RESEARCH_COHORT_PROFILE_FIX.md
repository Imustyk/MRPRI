# Исправление ретроспективного профиля корпуса

10 ноября 2026 года, ветка `feature/risk-specific-detection`.

Причина пустого блока: прежний график использовал `list_date`. В текущем корпусе это поле отсутствует у всех 152 378 процедур. У всех процедур есть `published_at`, полученное адаптером из `published_date` выгрузки; исходный экстрактор читает его из `package.publishedDate` OCDS (`src/mtender/ocds.py`, `extract_tender`). Это дата пакета, а не сертифицированная дата первого contract notice.

Вместо прежнего графика добавлен **«Ретроспективный профиль корпуса»**. Его научный смысл обозначен непосредственно в интерфейсе: текущие доступные оценки группируются по месяцу даты пакета в UTC. Это описание состава выгрузки и распределения оценок, а не динамика риска во времени, не сравнение запусков и не prediction at publication.

## Фактическое покрытие

- 152 378 процедур всего; 152 378 с пригодной датой пакета.
- 67 календарных месячных групп: октябрь 2018 — апрель 2024.
- В текущем ответе API все 152 378 датированных процедур имеют оценки.
- Без даты: 0. Некорректная дата: 0.

На экране показаны два отдельных графика: средний процентиль оценённых записей и количество оценённых/неоценённых записей. Среднее не взвешивается суммами контрактов. Под ними доступны точные месячные значения в таблице и пояснение источника дат. Разные объёмы групп видны явно; изменение состава групп не трактуется как изменение реального риска. Неполные крайние месяцы остаются видимыми как группы наблюдений, без экстраполяции до полного месяца.

## Защита от неверной интерпретации

- Другие даты не подставляются вместо отсутствующего `published_at`.
- Отсутствующие и ошибочные даты учитываются отдельно; timezone обязателен, epoch-placeholder отвергается.
- Оценка 0 входит в среднее как действительное значение; отсутствие оценки не превращается в 0. Нефинитные и выходящие за [0, 100] значения не входят в среднее.
- Пустые календарные месяцы присутствуют с количеством 0 и средним `null`. Линия через месяцы без оценок не проводится. Используется линейное соединение наблюдаемых значений без сглаживающей интерполяции.
- В API явно указано `publication_time_certified=false` и `interpretation=retrospective_snapshot_cohorts`.
- Прежнее поле `monthly` API сохранено с прежней семантикой. Новая визуализация читает отдельное `snapshot_cohorts`. Это явная смена описательного показателя, а не тихая замена исходной даты.
- Исторические признаки t0, метки ANSC и результаты формальной валидации этим графиком не подтверждаются; MTA-0020 не запускался.
