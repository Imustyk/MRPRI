## 2. Прогресс ручной проверки (§2/§3/§5)

| Показатель | Значение |
|---|---:|
| Подготовлено документов | 50 |
| **Проверено человеком** | **1** (документ №1, подтверждено: `admitted`/`ansc_decision`/`confirmed`, стр. 8, полная цитата) |
| Пилот | 1 из 10 подтверждён; документы №2–№10 проанализированы, **значения предложены и ждут подтверждения** |
| Записи `reviewer_*`, заполненные без подтверждения | 0 |

Документы пилота №2–№10 разобраны по одной процедуре на документ: число страниц, резолютивная часть,
точная румынская цитата, номер решения (проверен на 1-й странице: №2 `03d-355-20`, №3 `03D-884-20`,
№4 `03D-541-20`, №8 `03D-704-19`, №1 `03D-563-19`), число жалоб, предварительный исход, признак
«решение ANSC или нет», связь с OCID. Документы без текстового слоя отрендерены визуально
(OCR — только вспомогательно). **Предварительные выводы в `reviewer_*` не записаны** — они будут
записаны синхронно в оба файла (пилотный + 50) только после явного подтверждения по каждому документу.

Спорные места (помечены, не решены за проверяющего): документ №2 (две жалобы с разными исходами →
документный `unknown` + маркер `multiple:`), №5 (письмо ANSC, а не нумерованное решение; исход
`withdrawn` на уровне жалобы), №8 (четыре жалобы, три `admitted` + одна `partially_admitted` →
документный `unknown` + `multiple:`). Документы №7, №9, №10 — не решения ANSC (письмо, решение
авторитативного органа, протокол рабочей группы) → `other_document` с пометкой `mislink:` в notes.

## 4. Мультижалобные документы (§4/§5)

| Документ | Жалобы | Исходы по жалобам |
|---|---:|---|
| №2 (`03D-355-20`) | 2 | 02/389/20 `rejected`; 02/402/20 `admitted` |
| №8 (`03D-704-19`) | 4 | 02/827/19, 02/832/19, 02/837/19 `admitted`; 02/836/19 `partially_admitted` |

Оба документа с разными исходами по жалобам получают **документный** `unknown` с маркером `multiple:`
(§5 протокола); исходы жалоб сохраняются отдельно и **не сводятся** — процедура с несколькими
жалобами никогда не считается несколькими независимыми процедурами. В машинной выборке мультижалобных
строк 2 (row 2 и row 21) — совпадает с ручным разбором.

## 5. Техническая помощь для оставшихся документов (§7)

Создан `scripts/48_ansc_review_assistance.py` — **свежий проход** по локальным PDF (не читает и не
копирует колонки предсказаний `ansc_review_sample_50.csv`), только чтение review-файлов, без записи
ни одной ячейки `reviewer_*`.

* `results/tables/ansc_review_assistance_50.csv` — 50 строк, все `assistance_status=prepared_not_reviewed`
  (ни одной несуществовавшей человеческой подтверждения);
* `results/ansc_review_pages/row{NN}_p{P}.png` — 50 изображений (резолютивная, иначе последняя, страница);
* текстовый слой: 31 text / 12 garbled / 6 scan / 1 partial; локальных PDF: **50/50**;
* подсказки типа документа: 11 `ansc_decision` / 38 `other_document` / 1 `uncertain`;
* свежие подсказки исхода: 37 `unknown`, 13 классифицированы (4 admitted / 3 partially / 3 rejected / 3 withdrawn);
* подсказки связи с процедурой: 41 confirmed / 8 uncertain / 1 rejected;
* строки пилота в файле: 1, 2, 5, 8, 12, 14, 15, 21, 28, 37.

`fresh_outcome_hint` — **техническая подсказка, а не истина**: она не записывается в `reviewer_*` и не
выдаётся за экспертное заключение; равенство двух алгоритмов не является подтверждением. Известное
ограничение движка `scripts/43` (формулировка «Se respinge ca neîntemeiată…» не распознаётся) намеренно
**не исправлялось** во время проверки — это измеряемая ошибка извлечения, её покажет §9.
