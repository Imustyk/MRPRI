# MTA-0016/MTA-0017: реестр случаев — сопоставление с MTender

Реестр: `data/external/case_registry.csv`. Схема: `docs/case_registry_schema.md`. Дата: 2026-11-02. **Только измерение**: production остаётся v0, реестр не наполняется автоматически, сетевые запросы не выполняются (флаг `--allow-network` ничего не открывает в этой версии; `--raw-scan` только читает локальные `data/raw/ocds_packages`).

- Метка реестра смещена к крупным и громким случаям; сравнение с базовым ранжированием «только размер» обязательно.
- Журналистские материалы (уровень C) — не доказательство нарушения.
- Результат показывает приоритизацию, а не наличие коррупции.
- Индикатор потенциального риска, а не доказательство коррупции/нарушения. Требуется проверка компетентным органом.
