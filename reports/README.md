# reports/

Отчёты методологического цикла (октябрь 2026). Индекс:

| Файл | Что содержит | Генерируется |
|---|---|---|
| `bias_audit.md` | Аудит смещения полос риска (раздел E): 79 групп в 13 измерениях (размер/тип/бюджет заказчика, регион заказчика и поставщика, отрасль, тип процедуры, полоса стоимости, стаж и размер поставщика, год, период, полнота публикации), disparity ratio с ДИ, распределение полос и перцентилей, условные отклонения и калибровка по группам, вердикты «допустимо / предупреждение / нарушение», TPR/FPR против внешней метки, прокси-признаки, покрытие внешней метки, меры при нарушении (E.5) | `scripts/18_bias_audit.py` (не редактировать вручную) |
| `legal_and_sources.md` | Юридическая проверка (шаг 8): статус системы, формулировки, право на объяснение/оспаривание, персональные данные, автоматические решения + инвентарь внешних источников меток и статус их доступности (шаг 2.3) | вручную |
| `cycle_dynamics.md` | Сводная динамика метрик по циклам итеративной валидации: таблица версий v0–v3 с ДИ, график «цикл → метрики», вердикты по циклам | `scripts/22_cycle_dynamics.py` |
| `circularity_check.md` | Проверка круговой логики (раздел B): чистая ANOVA против внешних меток, разделение признаков на половины, ablation и permutation против внешней метки, рандомизированный контроль перетасовкой связей, ANOVA vs SHAP, вердикт по каждому признаку | `scripts/21_circularity_check.py` |
| `cycle_1.md`, `cycle_2.md`, `cycle_3.md` | Отчёты отдельных циклов шлифовки: одно изменение, полный набор метрик, сравнение с предыдущим циклом, решение | вручную по выгрузкам `scripts/20_cycle_framework.py` |

Журнал итераций (реестр версий v0–v3, что изменено и почему, итог остановки) — `cycle_log.md` в корне репозитория.

Связанные материалы: `docs/METHODOLOGY_CYCLE.md` (полный цикл), `docs/model_card.md` (карточка модели), `docs/thesis_text.md` (текст для дипломной работы), `results/methodology/final_verification.json` (перепроверка всех чисел).

Все материалы цикла сохраняют формулировку: **индикатор потенциального риска, а не доказательство коррупции**.
