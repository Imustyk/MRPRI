# Цикл 2 → версия v2_mean_rank

Один шаг итеративного протокола (`cycle_log.md`). Машиночитаемая выгрузка —
`results/methodology/cycle_framework.json`, строка `v2_mean_rank`.

## Что изменено (ровно одно)

Правило комбинирования ранжированных скоров четырёх детекторов в итоговое
ранжирование: **max-percentile → mean-percentile**. Полосы (голоса детекторов,
консенсус ≥3), порог и гиперпараметры не тронуты — изменение действует только
на порядок внутри списка.

## Зачем

Цикл 1 показал, что убрать поведенческий перекос через дубликат не вышло;
max-percentile чувствителен к одному выброшенному детектору (ранжирование
определяется худшим перцентилем). Альтернатива — средний перцентиль —
кандидат на более стабильное ранжирование при том же ансамбле.

## Сравнение с предыдущим циклом (v1 → v2 и v0 → v2)

Главный результат цикла — **знак раскола по периодам**: на tuning (2018–2021)
mean-percentile значимо хуже max-percentile (Δ −0.033, ДИ не пересекает 0),
на holdout (2022–2024) — лучше (0.544 против 0.518). Протокол принимает
решения по tuning → версия **отклонена**. Парадокс усиливает вывод о
периодной нестабильности внешней связи (см. «Что не удалось подтвердить»):
правило ранжирования, выученное на одном периоде, работает наоборот в другом.

Полезное побочное наблюдение, зафиксированное для автора: средний перцентиль
вдвое стабилизирует верх списка по сидам (Jaccard top-200 0.479→0.671 —
единственная версия, проходящая порог C2≥0.60). Если когда-нибудь появится
устойчивый внешний источник, кандидат стоит вернуть в игру.

## Решение

Отклонено по протоколу (решение по tuning; значимая деградация). PSI дрейфа
ухудшился (0.29→0.41). Критерии остановки: 4/8 (C2 Jaccard PASS, C5 на
holdout и C7 — слой нормативных объяснений, добавленный позже и
ретроактивно проходящий; остальные как у v0; C6 добавлен позже по
требованию автора — см. `cycle_log.md`).

Индикаторы потенциального риска, а не доказательство коррупции.
