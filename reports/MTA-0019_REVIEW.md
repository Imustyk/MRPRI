# MTA-0019 — предварительный отчёт о независимой проверке исходов ANSC

**Дата:** 2026-11-08. **Ветка:** `feature/risk-specific-detection`. **Режим:** только измерение.
Production v0, frontend, ETL 00–11 и существующие модели не изменялись; обучение и научное сравнение
моделей не выполнялись (это MTA-0020); массовая загрузка PDF не запускалась.

> An upheld ANSC complaint indicates an administrative procurement dispute outcome and does not constitute proof of corruption.
>
> Индикатор потенциального риска, а не доказательство коррупции/нарушения. Требуется проверка компетентным органом.

> **Главный вывод в одном предложении:** пакет для ручной проверки подготовлен полностью, но
> **ручная проверка не начата (0 из 50 документов), поэтому метрики качества не считались, внешняя метка
> `ansc_upheld` не создана, и готовность меток для MTA-0020 НЕ подтверждена.**

## 5. Качество (§5): метрики НЕ считались

`scripts/45_ansc_review_metrics.py` расширен и на реальных данных возвращает:

```
$ .venv/bin/python scripts/45_ansc_review_metrics.py
refusing to compute metrics: the manual review is incomplete ...
{"status": "awaiting_manual_review", "n_labeled": 0, "n_total": 50,
 "n_missing": 150, "metrics": null}      # 150 = 50 строк × 3 обязательных поля
exit=5
```

**Accuracy, Precision/Recall/F1, Macro-F1, матрица ошибок — не вычислены** (так и должно быть до полной
разметки). Что будет посчитано после разметки (контракт закреплён тестами):

* Accuracy, per-class P/R/F1, Macro-F1 (7 классов), матрица ошибок — **только на документах,
  подтверждённых как решения ANSC** (`reviewer_document_type = ansc_decision`);
* доля `unknown` (ручная и извлечённая); доля неправильных связей
  (`reviewer_link_verified = rejected` или маркер `mislink:`);
* отдельно метрики на подмножестве со связью `confirmed`;
* качество обнаружения **типа документа** по всем размеченным строкам (машина «решение/не решение» ↔
  `ansc_decision`/`other_document`/`uncertain`; `uncertain` не подмешивается в бинарный сплит);
* разбивка текстовый PDF ↔ скан; счётчик документов с несколькими жалобами (`multiple:`);
* в отчёте явно указано: **стратифицированная выборка 50 документов не обязательно репрезентативна**
  для всего корпуса.

Прежний контракт (MTA-0018: отказ при пустых `reviewer_outcome`, невалидные значения → exit 6, полный
расчёт при 50/50) сохранён — 7 старых тестов проходят без изменений.

## 6. Правила пригодности меток (§6)

Создан `scripts/47_ansc_upheld_labels.py`:

* **отказ до полной разметки:** незавершённая проверка → exit 5, в JSON только прогресс, **файл меток
  `data/external/ansc_upheld_labels.csv` НЕ создаётся** (подтверждено: файла нет); невалидные значения →
  exit 6; структурно неверный вход → exit 4;
* правила: `ansc_upheld = 1` при `admitted`/`partially_admitted`; `0` при `rejected`; **`NULL`** при
  `inadmissible`/`withdrawn`/`terminated`/`unknown`, при любом типе ≠ `ansc_decision`, при неподтверждённой
  связи и при строках с маркером `multiple:`;
* **несколько жалоб не сводятся:** каждая строка = документ/решение со своей меткой; несколько
  документов одной процедуры сохраняются отдельно, конфликтующие бинарные метки процедуры
  *сообщаются*, но не объединяются;
* **даты решений и утечка из будущего:** даты сверяются с `ansc_outcomes.csv`, даты позже момента
  генерации помечаются как кандидаты утечки; в JSON — правило «метка может попасть в модель только со
  дата ПОСЛЕ даты решения»;
* **скан утечки в признаки:** литерал `ansc_upheld` сканируется в скриптах 00–15 и `backend/` ДО всего
  остального; при обнаружении — exit 7 без записи меток (регрессионный тест на реальном дереве: чисто);
* **удовлетворённая жалоба ANSC не является доказательством коррупции** — дисclaimer в каждой
  строчке артефакта.

На текущих данных: **exit 5, `labels: null`**.

## 8. Ограничения

1. **Главная:** нет ни одной ручной метки — ни одна цифра §4–§6 не является результатом проверки.
2. Машинная выборка `ansc_review_sample_50.csv` содержит предсказания: её нельзя открывать проверяющему
   до завершения разметки (слепота).
3. Стратифицированная выборка 50/7 295 не обязана быть репрезентативной; `inadmissible`/`terminated`
   в пуле отсутствуют; сканов 5/50; OCR ≤3 последних страниц с искажением диакритики.
4. Песочница PDF и `results/**` вне git — без них воспроизводимы только тесты и чтение отчётов.
5. Доступность документов зафиксирована на 2026-11-08; возможны апелляции и судебные изменения.
6. Результат извлечения MTA-0018 (138 классифицированных, 98.1% `unknown`) остаётся **правилом, а не
   подтверждённой истиной** до ручной проверки.

## 9. Заключение о готовности к MTA-0020

**Метки для MTA-0020 ГОТОВЫ НЕ ЯВЛЯЮТСЯ.** Качество извлечения **не подтверждено**: человеком
проверено 0 из 50 документов. Всё, что сделано: слепой пакет и пилот подготовлены, правила меток и
отказы автоматизированы и протестированы, метрики и метка `ansc_upheld` заблокированы до полной
разметки. **Следующий шаг — ручная разметка 50 документов (начать с пилота 10)** по
`docs/ANSC_REVIEW_GUIDE.md`; после этого станут возможны §4 (сопоставление), §5 (метрики), §6 (метки)
и лишь затем MTA-0020.
