## 2. Извлечение исходов (шаг 3, `scripts/43`)

Запуск на реальной выборке (0 из 50 размечено):

```
$ .venv/bin/python scripts/45_ansc_review_metrics.py

{"status": "awaiting_manual_review", "n_labeled": 0, "n_total": 50,
 "n_missing": 50, "metrics": null}
```

**Exit 5, `metrics: null`** — Accuracy/Precision/Recall/F1/матрица ошибок не вычислены; невалидные значения
дают exit 6; полный расчёт возможен только при 50/50 корректных экспертных метках. Поведение закреплено
регрессионными тестами `tests/test_ansc_metrics.py`.

## 6. Ограничения

### 6.1 Стратифицированной выборки

1. **50 из 7 295 (0.7%)** — генерализация ограничена; для редких классов (rej 10, part 21, withd 7 в пуле)
   выборка забирает 3–4 документа, разброс оценки большой.
2. **Непропорциональное распределение** (минимум 3 на класс) — намеренное: редкие классы должны быть
   представлены. «Наивная» оценка по выборке завышает вес редких классов; при экстраполяции нужно взвешивание
   на доли пула.
3. **`inadmissible` и `terminated` отсутствуют** — в пуле 0 документов, заполнить искусственно нельзя;
   метрики по этим двум классам на выборке будут нулевыми по построению.
4. **`unknown` занимает 37/50 (74%)** — отражает долю пуле (98.1%), но ограничивает объём проверяемых
   резолютивных частей (13 документов).
5. Выборка покрывает **опрошенные документы ANSC** (сильные кандидаты), а не все жалобы: 28 URL с HTTP 400,
   178 сбоев скачивания и 249 не-PDF в выборку не попадают.
6. Дедупликация по URL: 44 уникальных ocid из 50 — одна процедура может быть представлена двумя документами.
7. Сканы — только 5/50: качество OCR проверяется лишь частично.

### 6.2 OCR и цитат

1. OCR выполняется только на последних ≤3 страницах скана с конца и только при отсутствии текстового слоя;
   `tesseract -l eng` искажает румынские диакритики — цитаты сканов могут отличаться от оригинала.
2. Повторный OCR в верификации **не детерминирован** (совпадение подтверждает достижимость страницы, но не
   заменяет ручную проверку); для несовпадений предусмотрен вердикт `manual_visual_check` (предупреждение,
   не проход).
3. Номера решений в инвентаризации не извлекались для сканов — 290 документов с номером занижает истинное
   число решений в корпусе.
4. 15 документов без извлекаемого текста не поддаются классификации в принципе.

### 6.3 Методические

1. Извлечение — **правило, а не модель**: цифры §2 не оценка качества модели и не доказательство чего-либо;
   автоматические исходы не подтверждены вручную.
2. Привязка документ→процедура достоверна при однозначном URL (здесь 100%) либо по tender id в тексте (41.1%);
   остальное — пометка `link_ambiguous` (в этом прогоне отсутствует).
3. Возможны ошибки самой классификации (адресаты проверят их вручную), апелляционное смещение и изменения
   решений судами.
4. Доступность документов зафиксирована на момент прогона (2026-11-08).
