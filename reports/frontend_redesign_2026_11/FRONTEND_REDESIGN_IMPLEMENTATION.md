## Достоверность model reference

Добавлен read-only endpoint `/api/tenders/{tender_id}/model-analysis`. Прежние API-поля не удалялись; к Tender добавлено поле `score_provenance` с фактическими run_id и источником сохранённой записи.

Гистограммы строятся сервером по всем доступным конечным score **того же непустого run_id**, а не по клиентским 20 строкам. Ранг — midrank совпадающих сырых score внутри этой базы. Это отдельный описательный показатель, не переписанный `risk_score`.

В проверенном реальном примере источник — `mongodb.anomaly_scores`, запуск `detect-20261009T064837Z-8e1170`, база — 152 378 процедур. Суммы частот гистограмм сверены с каждым знаменателем. CSV fallback без run_id не приписывается detection_summary: сопоставимая база остаётся недоступной.

Параметры/признаки берутся только из сводки совпадающего запуска. MAD-порог читается из сохранённого z_threshold. Численная нулевая граница SVM подписана как следствие `score = -decision_function` из кода при совпадающей сводке. Сохранённые решения не переопределяются; расхождение с документированной границей показывается предупреждением. Contamination/nu не используется как порог score.

Не сохранены и не восстановлены по произвольной выборке:

- обучающие медианы/MAD и отклонения по отдельным признакам;
- подтверждённая численная граница IF/LOF для выбранной записи;
- локальные attribution через этот API, фактические деревья и соседи;
- версия модели, если в связанном источнике нет model_version;
- подобранные «похожие закупки»: база моделей прямо названа популяцией одного запуска, без заявления matched-peer сравнения.

## Сохранённые ограничения исследования

Наличие производных значений ETL не доказывает исходную полноту. В интерфейсе явно указаны заполнение срока 30 днями, fallback отношения на 1, clip, тождество двух buyer–supplier share, риск PN/EV и отсутствие сертификации t0. Unknown не переназначается в отрицательный исход.

Не менялись модели, обучение, веса, пороги, голосование, `features.csv`, ANSC labels, reviewer-поля, исходные score и результаты MTA. MTA-0020 не запускался. Новый UI не означает GO для формальной валидации.

Проверка выполнена в локальном Google Chrome, включая production-сборку и эмуляцию размеров экрана. Safari, Firefox, физические устройства и полноценный скринридер не проверялись; полная браузерная и WCAG-сертификация не заявляется.

Предшествующие изменения `styles.css`, удаление `_lang-bootstrap.html`, `docs/network-view/`, `notebooks/` и корневой `package-lock.json` сохранены отдельно. Новый дизайн вынесен в `product.css` для совместимости с существующей работой. Push не выполнялся.
