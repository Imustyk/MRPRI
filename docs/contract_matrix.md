# Матрица контракта (`docs/contract_matrix.md`)

**Матрица контракта — фиксированное соглашение между бизнесом и моделью.**
Для каждого KPI заранее зафиксировано: какие данные, какая метрика, какой
порог и какая проверка его подтверждают. Модель считается принятой **только
если матрица сходится**, то есть каждая строка имеет статус «выполнено»
(`met`) либо документированное «не проверяемо» (`not_verifiable`). Любая
строка «не выполнено» (`unmet`) означает, что контракт не сходится и модель
не принята — независимо от того, сколько остальных строк выполнено.

Машиночитаемый источник истины: [`contract_matrix.yaml`](contract_matrix.yaml).
Статусы зафиксированы на **2026-10-17** по артефактам цикла шлифовки.

## Как перепроверяется

```bash
.venv/bin/python scripts/23_check_contract.py          # exit 1, пока контракт не сходится
.venv/bin/python scripts/23_check_contract.py --soft   # только отчёт, всегда exit 0
```

Скрипт читает матрицу и артефакты последнего цикла, пересчитывает статус
каждой проверяемой строки и падает с понятным сообщением, если:

- какая-либо строка не выполнена — модель не принята;
- у метрики нет источника (артефакт отсутствует на диске);
- записанный статус больше не совпадает с пересчитанным — матрица устарела;
- KPI модели не ссылается ни на один существующий бизнес-KPI;
- строка «не проверяемо» не имеет задокументированной причины и ссылки на
  документ.

## Не проверяемо (документированные исключения)

Строки со статусом «не проверяемо» — это не пройденные проверки, а
зафиксированные границы применимости. Контракт не считается сходившимся
на их основании как на «выполненные»; каждая имеет причину и ссылку на
документацию:

- **B8.** AAP публикует поставщика, а не пару «заказчик–поставщик»: внешняя
  проверка поведенческих признаков-связей структурно невыполнима на
  доступных источниках (`docs/thesis_text.md`, «Что не удалось
  подтвердить», п. 2).
- **B9.** legis.md блокирует автоматические запросы (Cloudflare 403),
  decisions.ansc.md недоступен по DNS: инвентаризация внешних источников
  не завершена (`reports/legal_and_sources.md`, помечен «требует
  проверки»; частично разблокировано 2026-10-17 — корпус RAG скачан,
  `docs/rag_sources.md`).

## Юридические и этические условия (раздел I)

- **Допустимость признаков (B6/M14).** В модели нет защищённых атрибутов
  (пол, национальность, вероисповедание, возраст); признаки построены только
  на атрибутах самих закупок из открытых данных. Единственный сильный
  прокси структурных групп — определительный («первый контракт» ↔ счётчик
  контрактов поставщика) и задокументирован в разделе E.
- **Право на объяснение (B5/M15).** Для любой процедуры корпуса существует
  разбор: вердикты детекторов и пять сильнейших SHAP-вкладов в плоском
  тексте (`scripts/17_explain_ocid.py`). Ограничение зафиксировано: SHAP
  точен только для IsolationForest; для LOF и One-Class SVM per-feature
  вклад невычислим по построению, и скрипт сообщает об этом вместо
  выдуманных чисел.
- **Объяснение с нормативной опорой (B10/M16/M17).** Каждая процедура
  high/critical получает разбор с цитатами официальных актов (закон
  131/2015, методматериал AAP, реестр интердикций). Защиты слоя: ответы
  извлекательные (цитата дословна и перепроверяется по корпусу —
  галлюцинация структурно невозможна и всё равно контролируется, C7),
  явный отказ при отсутствии фрагментов, нейтрализация инструктивных
  вставок в корпусе и запросе, запрет формулировок о вине/умысле, цитаты
  только опубликованных в MTender полей. Открытые пропуски корпуса
  (ГГ 957/2017, ГГ 1420/2016, решения ANSC) — `docs/rag_sources.md`.
- **Дисклеймер.** Все индикаторы — индикаторы потенциального риска, а не
  доказательство коррупции; внешняя метка AAP слабая (поставщик, не
  процедура; имя, не IDNO; решение обычно позже процедуры).

## Текущий итог

**9 выполнено · 16 не выполнено · 2 документировано не проверяемо** —
контракт **не сходится**: модель не принята. Основные блокеры: обогащение
вершины списка внешней меткой не подтверждено (B1, precision@200 = 0),
правило порога не окупается на tuning (B2), полосы не устойчивы во времени
(B3), критерий остановки C6 провален (B4), κ 0.19–0.25 против порога 0.40
(M11), LIME и SHAP не согласованы (M10: медиана Spearman −0.68, расхождение
систематическое и устойчивое). Новые строки объяснительного слоя (B10, M16,
M17 — 100% процедур high/critical получают объяснение с нормативными
источниками, 0 галлюцинаций, recall@3 = 1.0) выполняются, но не компенсируют
блокеры качества модели. Это согласуется с выводом цикла шлифовки:
закрывающее утверждение о сходимости ансамбля неприменимо.
