# docs/rag_sources.md — корпус нормативных актов (RAG-слой)

Дата проверки: **2026-10-17**. Скрипты: `scripts/25_rag_pipeline.py` (индексация),
`scripts/26_rag_eval.py` (оценка). Реестр источников как данные кода —
`SOURCES` в `src/mtender/rag.py`; хеши файлов — `results/rag/manifest.json`.

Правила корпуса:

- используются **только официальные документы**: либо предоставленные автором
  файлы, либо скачанные с официальных сайтов; каждый акт зафиксирован с
  издателем, URL, редакцией, датой загрузки и sha256;
- ни одна норма не цитируется «по памяти»: каждый ответ слоя собирается из
  дословных фрагментов корпуса с указанием акта и статьи; если нормы в корпусе
  нет — слой отказывается отвечать (проверяется в `rag_eval.json`);
- актуальность редакций ограничена датой загрузки (2026-10-17) и датой,
  указанной в самом документе; сверка с действующей редакцией на
  legis.just.gov.md требует сетевой доступности (Cloudflare блокировал
  автоматические запросы из окружения — см. раздел «Пробелы»).

## 2. Лицензии и правовой статус (требует проверки)

- Тексты нормативных актов RM — официальные публикации (Monitorul Oficial),
  публикуются государством; использование в академической работе с ссылкой на
  источник. **Актуальную редакцию и условия перепечатки требует проверки**
  юристом автора; сетевой версии legis.just.gov.md из окружения недоступны.
- PDF-зеркало FAOLEX (FAO) — зеркало официального текста; сверка с первичным
  Monitorul Oficial требуется (см. «Пробелы»).
- Методические материалы AAP и страница реестра — официальная публикация AAP
  на tender.gov.md; условия использования сайта требуют проверки.

## 3. Пробелы корпуса (документировано, не «упущено»)

Перечень ведётся кодом (`CORPUS_GAPS` в `src/mtender/rag.py`):

| Акт | Причина отсутствия | Статус |
|---|---|---|
| HG nr. 957/2017 (Regulamentul achiziţiilor publice) | текст публикуется на legis.md, который блокирует автоматические запросы (Cloudflare 403); альтернативных официальных копий в открытом доступе из окружения не найдено | требует проверки/загрузки (файл от автора решает) |
| HG nr. 1420/2016 (Regulamentul privind Lista de interdicţie) | то же ограничение | требует проверки/загрузки |
| Решения ANSC (оспоренные процедуры) | `decisions.ansc.md` недоступен по DNS из окружения | требует проверки/загрузки |
| Metodologia AAP privind monitorizarea conformităţii (официальные индикаторы риска) | найдено лишь упоминание в проекте постановления 2026 г.; сам текст методологии в открытых источниках из окружения не обнаружен | требует проверки/загрузки |

Следствие для оценки: recall на вопросах по этим актам заведомо низкий
(отражено в `reports/rag_eval.md`, раздел «Ограничения»); при пополнении
корпуса перезапускаются `scripts/25_rag_pipeline.py` и `scripts/26_rag_eval.py`.

## 4. Что фиксируется при каждом обновлении корпуса

1. URL и дата загрузки каждого файла, sha256, число фрагментов —
   `results/rag/manifest.json` (пересчитывается скриптом 25).
2. Редакция акта — из текста самого документа (заголовок/след правок), а не
   «по памяти».
3. Обновление этой страницы и `docs/data_provenance.md` (раздел «Нормативный
   корпус»).
4. Перезапуск оценки и актуализация статусов матрицы контракта
   (`docs/contract_matrix.yaml` → `scripts/23_check_contract.py`).
