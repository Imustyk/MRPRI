# Провенанс данных (`docs/data_provenance.md`)

Все основные выводы проекта построены на **реальных данных MTender
(OCDS 1.1)** и реальном внешнем источнике меток (список интердикций AAP).
Синтетика допускается только в тестах кода и для рандомизированных
контролей (раздел B.5 протокола) и **всегда помечается как таковая** —
см. раздел «Синтетика и рандомизированные контроли» ниже.

Хеши — SHA-256, сняты 2026-10-17. Способ воспроизведения — в конце файла.

## 3. Известные пропуски корпуса (зафиксированы, а не «починены»)

- **Неполнота публикации** (поле E, полнота публикации): заявки и награды
  опубликованы у 47 628 процедур; только награды — у 70 196; нет наград — у
  34 554 (итого 152 378).
- **Тип заказчика**: официальный `typeOfBuyer` у 57.8% процедур, эвристика
  по названию покрывает ещё 16.2% (union ≈ 74%); остальное — группа
  «unknown» в аудите смещения.
- **Регион поставщика** известен лишь для 31.3% процедур.
- **Бюджет заказчика** в OCDS отсутствует как поле; прокси — сумма
  контрактов заказчика; признак `buyer_scale` в корпусе целиком NaN.
- **Цены** отсутствуют примерно у 46% строк, **дедлайны** — у ≈23%.
- **7 712 строк** содержат плейсхолдер «locality», дающий артефактную
  группу «неизвестный регион» в аудите смещения.

## 4. Как воспроизвести хеши

```bash
# отдельные файлы
shasum -a 256 data/features/features.csv data/raw/blacklist/aap_lista_interdictie_2026-09-25.json

# манифест корпуса (152 378 файлов; «путь размер», сортировка, SHA-256)
find data/raw/ocds_packages -maxdepth 1 -name '*.json.gz' -print0 \
  | xargs -0 stat -f '%N %z' | sort | shasum -a 256
```

## 5. Ограничения провенанса

- Сетевой доступ из окружения **частично** работает (уточнено 2026-10-17):
  официальные сайты tender.gov.md и faolex.fao.org отвечают и используются для
  нормативного корпуса (раздел 6); legis.md блокирует автоматические запросы
  (Cloudflare 403), decisions.ansc.md недоступен по DNS. Лицензии и актуальные
  версии внешних источников (MTender, dataset.gov.md, AAP, а также ANSC,
  судебный реестр, ANI) по-прежнему **требуют проверки** —
  `reports/legal_and_sources.md` помечен «требует проверки», строка B9
  матрицы контракта — «не проверяемо».
- Корпус скачан однократно (2026-09-26) и заморожен для воспроизводимости
  цикла шлифовки: обновление MTender в ходе проекта не отражено.
